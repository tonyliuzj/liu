# Liu Portfolio

Static portfolio landing page built with HTML, CSS, and JavaScript.

## Edit

- Update portfolio text, projects, email, and social links in `script.js`.
- Adjust colors and layout in `styles.css`.

## Publish With GitHub Pages

1. Push this folder to a GitHub repository.
2. Open the repository on GitHub and go to **Settings** > **Pages**.
3. Choose **Deploy from a branch**.
4. Select your default branch, usually `main`, and choose the root folder `/`.
5. Save the Pages setting and wait for GitHub to publish the site.

Because `index.html` is in the repository root and all asset paths are relative, no build command is needed.
